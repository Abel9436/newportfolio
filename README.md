# newportfolio

Portfolio of Abel Bekele: AI engineer, automation expert and AI trainer.

Built with Next.js 16, React Three Fiber, GSAP and Lenis. A scroll-driven 3D figure, a slice shader tied to scroll speed, dark and light themes, and a contact form that sends through Resend.

## Run it

```bash
npm install
npm run dev
```

## Contact form

Copy `.env.example` to `.env.local` and set `RESEND_API_KEY`. Without a key the form falls back to opening the visitor's mail app.

## Editing content

All text lives in `src/content/profile.ts`.
